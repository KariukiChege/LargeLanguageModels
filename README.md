# Large Language Models Engineering

This repository contains engineering resources, experiments, and code related to Artificial Intelligence and Large Language Models (LLMs).

## Features & Focus Areas

- LLM Finetuning & Prompt Engineering
- Retrieval-Augmented Generation (RAG)
- Agentic Workflows
- Deployment & Optimization

## Getting Started

1. Clone this repository.
2. Set up a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```
3. Install dependencies (once added).
